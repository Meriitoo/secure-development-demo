# secure-development-demo

InvoiceHub invoice access and rendering component with executable security checks.
See [SECURITY-VERIFICATION.md](SECURITY-VERIFICATION.md) for the scope, local commands,
workflow jobs and controlled before/after experiment.

The real checks use the current PR code and pinned runtime requirements. Results
are not determined by branch names. This repository contains no Secure Workspace
database, private configuration, production secrets or application session data.
